## 🎯 Project List

### [Project 1: Weather Dashboard](./01-weather-dashboard/) 🌤️
**Difficulty**: Beginner  
**Time**: 2-3 hours  
**Topics**: API requests, JSON parsing, basic HTTP

Build a weather dashboard that displays current weather for any city using a public weather API.

**You'll Learn**:
- Making your first real API request
- Parsing JSON response data
- Handling API errors
- Working with API keys

**Prerequisites**: Modules 1, 2, 4, 6

---

### [Project 2: GitHub Profile Viewer](./02-github-profile-viewer/) 👨‍💻
**Difficulty**: Beginner to Intermediate  
**Time**: 3-4 hours  
**Topics**: REST APIs, Multiple endpoints, Data aggregation

Create an application that displays GitHub user profiles, repositories, and statistics.

**You'll Learn**:
- Working with a professional REST API
- Making multiple related API requests
- Handling pagination
- Working with rate limits
- Combining data from different endpoints

**Prerequisites**: Modules 1, 3, 4, 5 + Project 1

---

### [Project 3: Recipe Finder App](./03-recipe-finder/) 🍳
**Difficulty**: Intermediate  
**Time**: 4-6 hours  
**Topics**: Complex queries, State management, Data filtering

Build a recipe finder that searches recipes by ingredients, dietary restrictions, and cuisine type.

**You'll Learn**:
- Complex API query parameters
- Handling large datasets
- Managing application state
- Local data persistence (favorites)
- Working with nested JSON structures

**Prerequisites**: All modules + Projects 1 & 2

## 🛠️ General Setup Tips

### Python Projects
```bash
# Create a virtual environment
python -m venv venv

# Activate it
# On Windows:
venv\Scripts\activate
# On Mac/Linux:
source venv/bin/activate

# Install dependencies
pip install requests
```

### JavaScript/Node.js Projects
```bash
# Initialize project
npm init -y

# Install dependencies
npm install node-fetch
```

### Web Projects
- No special setup needed!
- Just open the HTML file in a browser
- Or use a local server: `python -m http.server`
