# Problem 2: Real-World API Uses (Medium)

## Instructions

Think about your favorite apps or websites. Choose **THREE** and research what APIs they might use.

For each app, provide:
1. Name of the app/website
2. Brief description of what it does
3. At least 2 APIs it likely uses
4. Explanation of how these APIs improve the user experience

---

## Example Format

```
App Name: Spotify
Purpose: Music streaming service that lets users listen to millions of songs

APIs Used:
1. Facebook API
   - Used for: Social login and sharing what you're listening to
   - Benefit: Makes login easier and lets you share music with friends

2. Payment APIs (PayPal, Stripe, etc.)
   - Used for: Processing subscription payments
   - Benefit: Secure payment processing without Spotify handling credit cards

How APIs improve experience: Users can log in quickly with existing accounts and 
pay securely. Spotify doesn't have to build these features from scratch.
```
