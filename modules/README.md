# API Learning Modules 📚

This directory contains structured learning modules that teach you about APIs from the ground up. Each module includes:
- **Tutorial Content**: Comprehensive explanations of concepts
- **Practice Problems**: Three problems ranging from easy to hard difficulty

## 📖 Modules

Work through these modules in order for the best learning experience:

### 1. [What Are APIs?](./01-what-are-apis/)
Learn the fundamentals of APIs, why they matter, and how they work in real-world applications.

### 2. [HTTP Basics](./02-http-basics/)
Understand the HTTP protocol that powers API communication on the web.

### 3. [REST APIs](./03-rest-apis/)
Explore REST architecture principles and best practices for building and consuming RESTful APIs.

### 4. [Making API Requests](./04-making-api-requests/)
Learn how to make actual API calls using various tools and programming languages.

### 5. [API Authentication](./05-api-authentication/)
Discover different authentication methods to secure API access.

### 6. [Working with JSON](./06-working-with-json/)
Master JSON data format, the most common format for API data exchange.

## 🎯 How to Use These Modules

1. **Read the Tutorial**: Start with the README.md in each module folder
2. **Complete Practice Problems**: Work through problem1.md, problem2.md, and problem3.md
3. **Check Solutions**: Compare your answers with the solutions provided in the README
4. **Move to Next Module**: Once comfortable, proceed to the next module

## 🚀 Ready for More?

After completing all modules, check out the [projects folder](../projects/) for hands-on projects that combine multiple concepts!
